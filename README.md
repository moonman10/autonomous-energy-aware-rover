# autonomous-energy-aware-rover

This project develops a low-voltage autonomous mobile robot that integrates electric-vehicle power-system concepts with robotics and embedded controls. The rover will use a smart BMS, battery supervisory monitoring, motor encoders, CAN communication, and ROS 2-based navigation to deliver small payloads between defined indoor locations.

A primary goal is to make the rover aware of its own electrical condition. It will monitor voltage, current, temperature, and faults; limit power when necessary; and evaluate whether a delivery mission can be completed safely based on available energy and thermal conditions.
